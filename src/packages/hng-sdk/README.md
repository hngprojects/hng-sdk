# hng-sdk

The main HNG SDK package. This package includes all HNG SDK utilities.

## Installation

```bash
npm install hng-sdk
# or
pnpm add hng-sdk
# or
yarn add hng-sdk
```

## Individual Packages

You can also install individual packages:

```bash
# Email utilities
npm install @hng-sdk/email
```

## Usage

```typescript
import { NotionMagicLinkEmail } from 'hng-sdk';
// or import from specific package
import { NotionMagicLinkEmail } from '@hng-sdk/email';
```
