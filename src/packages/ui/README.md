# @hng-sdk/ui

React UI component library for the HNG SDK.

## Installation

```bash
npm install @hng-sdk/ui
# or
pnpm add @hng-sdk/ui
# or
yarn add @hng-sdk/ui
```

## Usage

```tsx
import { Button, Card } from '@hng-sdk/ui';

function App() {
  return (
    <Card>
      <Button>Click me</Button>
    </Card>
  );
}
```

## Peer Dependencies

This package requires React 18+ as a peer dependency:

```bash
npm install react react-dom
```
